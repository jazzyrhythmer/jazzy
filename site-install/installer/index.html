The firmware accepts the original Puya 0x856014 and newer UC25HQ80 0xB36014. This page cannot read the chip ID through the current MIDI protocol; it does not identify hardware from its colour, logo or firmware name. Older installed firmware may still refuse update entry.

Recovery keeps the device’s boot-area match check. A V15/V16 mismatch is stopped rather than forced. Full hardware compatibility is not established by a successful browser check.

If installation stops, download the diagnostic report: it records the source, selected recovery, target SHA, browser, transfer phase and request counters. A failed final identity check may happen after the firmware has been written. If no MIDI loader is visible, this page cannot perform ROM/Transporter recovery.
